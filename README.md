### 📖 项目简介

 **SoulFrog** 是一个开源、免费、不定期更新的 Xposed 模块项目，专注于 Android 应用功能扩展与技术研究。
 
- ⚡ **精简高效**：以代码简洁和运行性能为优先。
- 🆓 **免费开源**：开放源码，供学习与技术交流。
- 🐸 **持续迭代**：不定期更新，呱！
